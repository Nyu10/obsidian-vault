### 1. Equity index futures ⭐⭐⭐⭐⭐

Pros:

- Very capital efficient.
- Lower financing costs than retail margin in many cases.
- No daily leverage reset.
- Widely used by institutions.
Cons:
- Requires learning margin mechanics.
- Can be dangerous if oversized.
This is the approach I'd research first if your goal is efficient, long-term leverage.

### 2. Modest portfolio margin ⭐⭐⭐⭐☆
Can work if
- The leverage is low.
- You have substantial cash reserves.
- You understand liquidation risk.

## This is something many investors miss

The first property teaches things you simply can't learn from YouTube:

- Which contractors are actually reliable.
- How to screen tenants without discriminating.
- How to handle maintenance requests.
- How much repairs really cost.
- How vacancy affects cash flow.
- What it's like to have $8,000 of unexpected HVAC work.


### Test #1 (today)
> Does this reduce my housing cost to a level I'm happy with while I live there?
If yes, great.
---
### Test #2 (future)
> If I move in 2–5 years, would I still be excited to own this property as a rental?
This is the one a lot of firs-time buyers skip.
If the answer is **no**, I probably wouldn't buy it.
